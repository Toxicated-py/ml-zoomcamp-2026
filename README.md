# Machine Learning Zoomcamp 2026

This repository contains my notes, practice notebooks, homework, experiments, and projects completed while studying the **DataTalksClub Machine Learning Zoomcamp 2026**.

The main purpose of this repository is to document my hands-on machine learning learning process and build a strong practical foundation in data science and machine learning.

## About the Course

Machine Learning Zoomcamp is a practical machine learning course by DataTalksClub. It covers the complete machine learning workflow — from data preparation and exploratory analysis to model training, evaluation, deployment, and production-oriented machine learning.

Official course repository:

https://github.com/DataTalksClub/machine-learning-zoomcamp

## Learning Approach

Rather than only completing the assignments, I use this repository to understand how each machine learning technique works.

The general workflow followed throughout the course is:

```text
Understand the problem
        ↓
Explore the data
        ↓
Clean and prepare the data
        ↓
Create features
        ↓
Split the dataset
        ↓
Train models
        ↓
Evaluate performance
        ↓
Tune the model
        ↓
Test on unseen data
        ↓
Use or deploy the model
```
